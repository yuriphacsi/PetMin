# Diario de diseño PetMin 3.0

Flujo físico: Inicio → Porción → Confirmar → orden única → consultar resultado → Historial. Error de red significa resultado incierto; no se reenvía. Horarios: editar local → enviar → ESP32 conserva y ejecuta con reloj válido.

Gaming: elegir perro/gato y nombre → escena 3D → cinco desafíos → logros persistentes. Sin conexión al dispensador. Perfiles reales en Ajustes no calculan dieta.

Material 3, seis destinos, porcentaje más gramos, mediciones desconocidas explícitas. Calibración guiada en pantalla y aplicada por USB. Sin botones ficticios de escaneo/tienda/nube.

Pendiente: observar a tres usuarios reales, registrar dificultades y corregir las tres principales. No se inventaron entrevistas ni tiempos.
