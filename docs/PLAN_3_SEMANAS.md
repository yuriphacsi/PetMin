# Plan para cuatro integrantes — tres semanas

Trabajar con un bloque de 60–90 minutos, cinco días por semana, y una sesión grupal de integración de 90 minutos. Presupuesto orientativo: 6,5–9 horas por persona/semana, compatible con reservar tiempo para otros cursos. Comprar/fabricar mecanismo y resolver problemas de hardware puede requerir tiempo adicional. Congelar funciones nuevas al finalizar el día 14.

| Responsable | Área principal | Evidencia |
|---|---|---|
| Integrante 1 | Android, compilación, conexión y UI | APK instalado, navegación y errores reales |
| Integrante 2 | Circuito, mecanismo, firmware y calibración | Tabla de masas, cierre seguro y porciones pesadas |
| Integrante 3 | Gaming, perfiles y recursos visuales | Dos mascotas, animaciones y cinco logros persistentes |
| Integrante 4 | Integración, pruebas, documentación e historial | Casos reproducibles, errores y presentación |

| Días | Trabajo y criterio de salida |
|---|---|
| 1–2 | Todos abren mismo ZIP; I1 compila Android, I2 compila ESP32 con servo deshabilitado, I3 revisa escena y fotos, I4 registra versiones/errores. No avanzar sin identificar los bloqueos de compilación. |
| 3–4 | I1/I2 conexión real y estado sin actuador; I2 verifica alimentación/tara; I3 revisa desafíos y legibilidad; I4 valida contrato y documenta montaje. |
| 5–7 | Calibración de varias masas y prueba supervisada de cierre. Primera porción medida, paro y pérdida de red. Meta: flujo Android→ESP32→historial comprobado. Si falla SG90, corregir mecanismo ahora. |
| 8–10 | Horarios con app cerrada, reinicio y sin NTP; historial/paginación/retención; edición de perfiles y foto. Gaming y progreso tras cerrar la app. |
| 11–13 | Series de 10 porciones; comparar pérdida de tolva con balanza externa. Probar atasco, sensor desconectado y reinicio durante entrega, con supervisión y cierre mecánico. |
| 14 | Congelar funciones; aceptar solo lo demostrado. Si precisión insuficiente, documentar rango usable y corrección de mecanismo, sin inventar resultados. |
| 15–17 | Corregir fallos; comprobar accesibilidad/rotación/pantalla pequeña y rendimiento. Ejecutar suite Android y compilar firmware final. |
| 18–19 | Generar APK, verificar instalación limpia y actualización, preparar guía y evidencias reales. |
| 20 | Ensayo de 8–10 minutos: conexión, lectura, porción, horario, historial, perfil y Gaming. Cada integrante explica su módulo. |
| 21 | Margen para fallos, empaquetado de código sin secretos, entrega y respaldo. |

Reunión breve: qué funciona, qué bloquea y siguiente prueba. Compartir cambios con Git en ramas android/hardware/gaming/datos al trabajar en sus equipos, revisar antes de fusionar. No dejar calibración y montaje para la semana final. Escaneo de mascotas, tienda y nube quedan fuera de estas tres semanas.
